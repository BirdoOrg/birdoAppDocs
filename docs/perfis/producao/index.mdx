# Instalação

O primeiro passo é instalar o BirdoApp no seu computador.
Durante a instalação, o aplicativo configura automaticamente as dependências necessárias, como o Python 2.7 e o ffmpeg, utilizados internamente pelo sistema.

👉 Veja mais detalhes na página:
[Guia de instalação do BirdoApp](../../instalacao.md)

# Configuração inicial
Após a instalação, ao abrir o BirdoApp pela primeira vez, você será guiado por uma configuração básica do app, do Estúdio e do Projeto selecionado.

👉 Leia mais em:
[Guia de configuração básico](../../configuracao.md)

:::info
    Na [configuração de local de projeto](../../configuracao.md#configuração-local-de-projeto) você deve escolher a função "DT"!
:::


# Inicializar o BirdoApp

👉 Após configurado, o BirdoApp inicia o janela para seleção do [modo de uso](../../modos-de-uso.md). você deve escolher o [Modo de Uso Para Estúdios](../../modos-de-uso.md#modo-estudio);

👉 Após a seleção do modo para Estúdios, o BirdoApp carrega a janela [principal](../../funcionalidades/principais/index.mdx) com as ferramentas disponíveis.

Para a produção/direção técnica (DT), todas as ferramentas estarão disponíveis:

* [***Assets***](../../funcionalidades/principais/assets.md): Ferramenta perimite criar ou abrir arquivos de assets do projeto escolhido.

* [***Abrir Cenas***](../../funcionalidades/principais/abrir-cena.md): Ferramenta que lista as cenas de Harmony disponíveis no servidor para a etapa de SETUP.

* [***Uploader***](../../funcionalidades/principais/uploader.md): Ferramenta que perimite subir arquivos para a estrutura no servidor do projeto. 

* [***Menu BirdoApp***](../../funcionalidades/menu/index.mdx): Ferramentas do menu BirdoApp dentro do Harmony.

* [***Ferramentas de ToolBars***](../../funcionalidades/toolbars/index.mdx): Ferramentas disponíveis nos _toolbars_ do BirdoApp dentro do Harmony.

:::tip
    Para o usuário DT, as ferramentas [***Abrir Cenas***](../../funcionalidades/principais/abrir-cena.md) e [***Publicar***](../../funcionalidades/menu/#publicar) permitem escolher em qual etapa (SETUP ou ANIM) você deseja baixar ou enviar as cenas. Se for usar estas ferramentas em produção com este perfil de usuário, preste atenção para este detalhe.
:::
